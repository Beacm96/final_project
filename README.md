# Meditrack

Meditrack is a web application developed as the Final Project for the Full Stack Development Master's program.

The application is being built with Django for the backend and will include a React integration for part of the frontend.

## Technologies

- Python
- Django
- Git
- GitHub

## Project Status

This project is currently under development.

```bash
git clone https://github.com/Beacm96/final_project.git
##Enter the project directory
cd final_project
##Create a virtual enviroment
python3 -m venv venv
##Activate it
